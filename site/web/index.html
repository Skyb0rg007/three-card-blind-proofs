    About this game

    This is the 3-Card Blind matchup modelled in the three-card-blind-proofs repository. Both players see everything, start at 20 life and start with their three cards in hand. City of Traitors is treated as already on the battlefield (spec/RULES.md S1). When Elixir shuffles B's library, A chooses the order, because 3CB resolves random effects in the way most favourable to the opponent.

    The rules engine is the repository's Rust port of the Rocq model (spec/Model.v), compiled unchanged to WebAssembly. It is checked against the native solver's differential walk, byte for byte.

    What is proved

    • When B goes first, B can force a win. Rocq checks this with a table of 1.5 million positions.
    • When A goes first, A can't force a win: B never loses. Whether B can force a win there is still open.

    When you play A and B goes first: certified play

    The computer plays B from the certificate, so it cannot lose. The page loads the same table Rocq checks for the B-first theorem (proofs/bfirst/Data.v, about 1.3 MB gzipped). At each turn start B takes the table's record for the position, and at each of its decisions it plays a move after which the checker Rocq runs still passes, ported to Rust and run in your browser. Rocq proves that whatever A does, B then wins within finitely many turns.

    The moves are certified to win, not the best or the fastest: B doesn't look for the quickest win, only one the certificate guarantees. It never offers or accepts a draw. If the game didn't start from a position the certificate covers (for example with other starting life totals), the page says so and the computer uses the heuristic search instead.

    Otherwise: a bounded search

    In the other set-ups the computer plays a bounded search, not proven-optimal play. It searches every decision of the current turn and several more turns, then scores the position with a heuristic: life totals, counters, Thopters, cards, and lethal threats. Those openings are unsolved for B's win, and the solver's other tables are far too big to ship to a browser.

    Walkers can grow forever and Elixir can loop, so games against the search can go on indefinitely. The page then offers a draw when a position repeats or the game runs long, and you can declare one at any time.
